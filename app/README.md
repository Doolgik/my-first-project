# Barber Lab — подбор стрижки

Мобильный веб-инструмент барбера. Клиент садится в кресло, барбер снимает четыре
ракурса, приложение размечает лицо в 468 точек, считает пропорции, подбирает
стрижку и объясняет выбор. Дальше — мастера, цены и ближайшие окна.

Десктопной версии нет намеренно: на широком экране показывается заглушка.

## Запуск

```bash
npm install
npm run dev     # http://localhost:5173, доступен и по адресу в локальной сети
```

Камера в браузере работает только по HTTPS либо на `localhost`. Чтобы открыть
с телефона по локальному адресу вида `http://192.168.x.x:5173`, нужен туннель
(`npx localtunnel --port 5173`, `ngrok http 5173`) или самоподписанный сертификат.

Полезные команды:

```bash
npm test        # логика замеров и подбора, 18 проверок
npm run build   # сборка в dist/
npm run preview # раздать собранное на :4173
npm run smoke   # прогон в браузере со скриншотами (нужен запущенный preview)
```

Демо-режим без камеры и клиента — добавить `?demo` к адресу. Показывает экран
подбора на синтетической разметке; удобно на встрече с барбершопом.

## Что здесь настоящее, а что нет

Работает по-настоящему:

- разметка лица (MediaPipe Face Landmarker, 468 точек, целиком в браузере)
- замеры пропорций: длина к ширине, челюсть, лоб, доли зон, асимметрия, поза
- классификация формы лица с честной оценкой уверенности
- подбор стрижки из каталога по правилам и обоснование
- коллаж из четырёх реально снятых ракурсов
- мастера, цены и расписание

Пока не настоящее:

- **фотореалистичная примерка.** Ключа генерации нет, поэтому вместо рендера
  показывается контур причёски, построенный по разметке головы: он честно
  передаёт объём и пропорции, но не текстуру волос. Подключается через
  `src/lib/generate.ts` — см. ниже.
- **данные барбершопа.** Мастера, цены и слоты лежат в `src/lib/shop.ts`.
  В проде они придут из CRM шопа.

## Приватность

Кадры не покидают телефон: модель разметки и WASM отдаются с того же хоста,
распознавание идёт локально, ничего не сохраняется и не отправляется на сервер.
Клиент не идентифицируется — по разъяснению Роскомнадзора фото лица считается
*биометрическими* персональными данными только когда оператор использует его для
установления личности. Здесь этого не происходит, поэтому режим 572-ФЗ не
включается. Логика зависит от этого свойства: как только появится хранение
привязанных к человеку снимков, юридический режим меняется.

## Подключение генерации

Ключ модели не должен попадать в браузер — фронт ходит на свой эндпоинт, а тот
уже к провайдеру. Задать адрес:

```bash
echo 'VITE_GENERATION_ENDPOINT=https://api.example.com/generate' > .env.local
```

Контракт эндпоинта описан в `src/lib/generate.ts`: принимает кадр анфас,
идентификатор и технические параметры стрижки, возвращает `{ image }`.
Пока переменная не задана, приложение показывает контур и прямо пишет об этом
на экране.

## Устройство

```
src/lib/faceMetrics.ts   замеры по разметке, формы лица, поза, асимметрия
src/lib/catalog.ts       каталог стрижек с правилами подбора
src/lib/recommend.ts     скоринг и тексты обоснования
src/lib/silhouette.ts    построение контура причёски по разметке
src/lib/faceMesh.ts      обёртка MediaPipe
src/lib/shop.ts          барбершоп: мастера, цены, расписание
src/lib/generate.ts      слой фотореалистичной генерации
src/lib/demoScan.ts      синтетический скан для режима ?demo
src/screens/             экраны: Intro, Scan, Profile, Result, Booking
tests/logic.test.ts      проверки замеров, классификации и подбора
```

Модель разметки и WASM (~25 МБ) в репозитории не лежат — их кладёт
`scripts/fetch-assets.mjs`, который сам запускается перед `dev` и `build`.

## Что осознанно не сделано

- **Линия роста волос, плотность и тип завитка не измеряются.** Разметка лица их
  не видит, поэтому барбер отмечает их руками на экране «Отметки мастера».
  Притворяться, что мы их посчитали, было бы враньём — а на подбор они влияют
  сильнее формы лица.
- **Связка «форма лица → стрижка» — парикмахерская эвристика, а не наука.**
  Правила описывают, как стрижка меняет видимые пропорции, и в этих пределах
  честны. Уверенность классификации показывается на экране, у пограничных
  контуров она низкая и называется вторая версия формы.
